# Arbeitsanweisung — YouTube

## Gemeinsame Basis

- Kanalnische: **Alltagspsychologie & menschliches Verhalten**
- Themen-System: `YOUTUBE_THEMEN_SYSTEM.md`
- Bildwelt: `YOUTUBE_STYLE_LOCK.md`
- Visual-Regeln: `YOUTUBE_VISUAL_BEAT_RULES.md`
- jede sichtbare menschliche Figur muss Stickman bleiben
- psychologische Aussagen sauber belegen und Unsicherheit transparent machen
- keine Diagnosen, Therapieanweisungen oder pseudowissenschaftlichen Versprechen

## Longform

Pfad: `longform/`

- reguläre Videos mindestens 10:00 Minuten, sofern das Thema die Länge sinnvoll trägt
- Ziel meist 11–14 Minuten
- viele präzise Visual Beats, keine langen Sammelbilder
- vollständige 01–06-Projektstruktur

## Reels

Pfad: `reels/`

- keine 10-Minuten-Mindestlänge
- kurze Projekte dürfen deutlich dichter geschnitten sein
- trotzdem gilt: ein neuer wichtiger visueller Gedanke bekommt grundsätzlich einen eigenen Beat
- keine Füllbilder nur für künstliche Bildanzahl
- dieselbe Stickman-Welt wie Longform
- vollständige 01–06-Projektstruktur verwenden, damit Audio, Bilder, Quellen, Schnitt, Export und Projektdateien sauber getrennt bleiben

## Produktionsfolge

THEMA + QUELLEN + CLAIM-CHECK → finales Skript → Phase 1 Visual Beats → Phase 2 Assets + Audio → Phase 3 Timing/Render → Final-QA.

Keine Phase überspringen. Skriptänderungen setzen nachgelagerte Planung zurück.

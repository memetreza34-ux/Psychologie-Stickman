GLOBAL WORLD — HARD LOCK
Create a cinematic 2D illustrated frame for a modern psychology YouTube channel. Keep one consistent visual world: stylized stickman-inspired characters with large simple round heads, minimal expressive faces, compact clothed torsos, very slim simplified limbs, simple hands and shoes. Characters are clearly simplified but NOT bare line stickmen and NOT normal cartoon humans. Use colorful believable environments, clean slightly organic outlines, soft cel shading, natural depth, purposeful cinematic framing, controlled colors, warm/cool lighting and small meaningful details. When no character is needed, schemas, text graphics, objects, comparisons and metaphors must use the exact same linework, color, shading, lighting and illustration quality. No photorealism, no 3D/Pixar, no anime, no corporate vector look, no whiteboard doodle style.

SCENE TYPES
- CHARACTER_SCENE: relatable character action in a believable place
- SCHEMA_EXPLAINER: illustrated mechanism/relationship with exact short labels; character optional
- OBJECT_METAPHOR: symbolic object/environment; character optional
- COMPARE_VISUAL: two states/options in one coherent frame
- TEXT_ILLUSTRATION: short phrase integrated into a strong illustration

Target mix is roughly 55/15/15/10/5, but choose the type that explains each beat best.

WORLD CONSISTENCY
Same world does not mean same room or person. Vary character identity, clothing, location, camera and lighting according to the beat. Repeat a person only for genuine continuity. Non-character images must still look as if created by the same illustrator for the same animated film.

CHARACTER DIRECTION
When people appear: use clothing appropriate to role/place, readable posture/emotion, simple individuality through color, hairstyle cue, glasses or accessory. Keep anatomy simplified.

ENVIRONMENT + CAMERA
Use recognizable real locations and meaningful details. Plan foreground/midground/background when useful. Choose medium, wide, close, side, over-shoulder, high or low angle according to storytelling. Background detail must support, not compete.

VISIBLE TEXT — GOOGLE FLOW ONLY
NO REMOTION TEXT.

Allowed planned text:
- Cover: main title + optional short psychology-topic kicker
- Keyword: normally 1–5 words
- Schema: optional short title + up to 3 short labels
- Comparison: optional short title + up to 2 short labels
- Text illustration: one short phrase

Every visible word must be explicitly listed in the current scene. All unplanned background text is forbidden. Screens, books, posters, packaging and documents use abstract marks unless their text is explicitly planned.

TYPOGRAPHY
Clean modern editorial typography integrated into the illustrated world. Safe margins. No meme/sticker style, no 3D/glow text, no corporate PowerPoint feel.

REFERENCE SYSTEM
Use approved files from assets/cinematic-psychology-world/ as STYLE/CHARACTER-FAMILY/LINEWORK/COLOR/SHADING/LIGHTING references only. Do not clone exact character, room, pose, composition or readable text.

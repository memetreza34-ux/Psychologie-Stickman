YOUTUBE PRODUCTION RULES — GOOGLE FLOW HANDOFF

FORMAT
16:9 / 1920x1080 / 30 fps. Preserve PSYCHOLOGY_STICKMAN_WORLD_V1.

ONE ENGLISH PROMPT
Codex prepares one complete 02-google-flow/google-flow-prompt.txt. All instructions/image descriptions are English; visible image text and narration are German. Google Flow generates every image itself, including references. No external Codex image required.

INITIAL OUTPUT ONLY
Design script-specific individual character references, then exactly three different standalone cover candidates. No video scenes yet. The only approval pause is the cover selection inside Google Flow; no separate character-approval round.

AFTER COVER SELECTION
Winner is the independent thumbnail; delete rejected covers after selection. Character references preserve identity, selected cover preserves style. BILD 01 is an ordinary first story scene, never the cover. Generate scenes in five-image batches, immediately inspect/rename as 01.png through NN.png. Regenerate failed/missing files and continue without further questions.

TEXT AND VISUALS
Only planned exact German text. Each beat chooses its best representation and one clear visual idea. Objects, environments and schemas share the same illustration world. No mixed normal-human/stickman anatomy or repeated staging without new information.

FINAL QA AND DOWNLOAD
Check all images against script, identity, props, scene count, filenames, 16:9 format and exact German labels. Collect thumbnail.png, character-reference files and all numbered scenes in one flat google-flow/ folder; provide google-flow.zip only when actually created and inspected. If the interface cannot export ZIP/files, report the precise limitation and provide separate images.

LOCAL IMPORT
Scenes -> 03-bilder/; thumbnail -> 05-export/thumbnail.png; character references -> 99-intern/reference-notes/. No thumbnail/reference in the numbered video scenes. Existing videos are not retroactively changed.

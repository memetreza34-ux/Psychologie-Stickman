- Quellen/Claim-Check: fertig
- Bilder: noch zu generieren
- Audio: noch offen
- Final-Render: noch offen

## Flow-Ablauf

1. `02-google-flow/flow-3-image-prompts.txt` öffnen.
2. `FLOW PROMPT 1` in Google Flow einfügen → Bilder 01–03 erzeugen.
3. Bild 01 nur akzeptieren, wenn der Charakter wirklich ein STRICT STICKMAN ist.
4. Das freigegebene Bild 01 als Charakterreferenz für Prompt 2 und 3 verwenden, wenn Flow dies unterstützt.
5. Prompt 2 → Bilder 04–06.
6. Prompt 3 → Bilder 07–09.
7. Nur fehlerhafte Bilder neu generieren.

Wichtig: keine normalen Cartoon-Menschen. Große einfache Köpfe, minimale Gesichter, schmale Körper, sehr dünne Arme/Beine.

## Flow-Ablauf

1. `02-google-flow/google-flow-prompt.txt` öffnen.
2. Diese eine Datei enthält globale Bildweltregeln + alle Szenen 01–09.
3. Bild 01 zuerst generieren und nur akzeptieren, wenn der Charakter wirklich ein STRICT STICKMAN ist.
4. Danach weitere Bilder aus derselben Master-Datei erzeugen.
5. Wenn Flow eine Charakterreferenz erlaubt, das freigegebene Bild 01 für wiederkehrende Figuren verwenden.
6. Nur fehlerhafte Bilder neu generieren.

Es gibt **keine Aufteilung in mehrere Flow-Prompt-Dateien**.

Wichtig: keine normalen Cartoon-Menschen. Große einfache Köpfe, minimale Gesichter, schmale Körper, sehr dünne Arme/Beine.

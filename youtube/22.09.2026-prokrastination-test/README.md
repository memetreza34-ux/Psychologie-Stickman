# YOUTUBE TEST 01 — PROKRASTINATION

## Thema
**Warum schieben wir Dinge auf, obwohl wir wissen, dass es uns später stresst?**

## Ziel dieses Tests
Dies ist der erste längere, echte YouTube-Test des Kanals. Er soll nicht wie ein Reel behandelt werden, sondern wie ein reguläres Longform-Video mit vollständigem Produktionsablauf.

## Format — HARD LOCK
- YouTube Longform
- 16:9
- 1920×1080
- 30 fps
- horizontal / Landscape
- Remotion-Komposition: `Phase3YouTube`
- Reel-Format 9:16 ist für dieses Projekt ausdrücklich falsch.

## Ziel-Länge
- ungefähr 5 Minuten
- Skript: ca. 815 gesprochene Wörter
- Phase 1: 58 geplante Visual Beats / Bilder
- angestrebte durchschnittliche Bilddauer: ungefähr 4–6 Sekunden
- finale Dauer wird aus dem final bearbeiteten Voice-over bestimmt und nicht künstlich auf exakt 5:00 gestreckt.

## Bildwelt
Universal Editorial Stickman World v1.2.

Für diesen Test ist die Bildqualität wichtiger als eine starre Bildanzahl. Trotzdem gilt: jeder der 58 Visual Beats braucht eine eigene starke visuelle Idee. Keine Füllbilder, keine reine Wiederholung derselben Pose und keine späteren Informationen vorwegnehmen.

## Hauptfigur
Wiederkehrender neutraler junger erwachsener Stickman in modernem 2026-Alltag. Dunkelblauer Pullover, anthrazitfarbene Hose, helle Schuhe. Diese Merkmale bleiben in Alltagsszenen stabil. Concept-/Research-Szenen dürfen die Figur abstrahieren, die Stickman-DNA bleibt aber identisch.

# Stickman YouTube — Produktionsrepo

Dieses Repository ist ein technischer Ableger von `memetreza34-ux/faceless-erklaerkanal` für YouTube-Longform.

## Kanalpositionierung

**Alltagspsychologie & menschliches Verhalten**

Kernversprechen: Warum Menschen denken, fühlen und handeln, wie sie es tun — verständlich, evidenzorientiert und visuell erklärt.

Verbindliches Themen-System: `channels/dinge-erklaert/youtube/YOUTUBE_THEMEN_SYSTEM.md`

## Bildwelt

**Universal Editorial Stickman World v1 — LOCKED**

Verbindlicher Style-Lock: `channels/dinge-erklaert/youtube/YOUTUBE_STYLE_LOCK.md`

Die Bildwelt kombiniert minimalistische Stickman-Figuren mit deutlich reicheren 2D-Umgebungen. Räume, Architektur, Kleidung, Gegenstände, Perspektive und Licht dürfen realitätsnah wirken, während die Figuren bewusst stilisiert bleiben. Farben sollen natürlich und klar sein statt permanent ausgewaschen oder beige. Der Detailgrad darf je nach Szene von abstrakt/grafisch bis zu historisch oder örtlich detailreich wechseln, ohne die gemeinsame visuelle DNA zu verlieren.

## Was technisch übernommen wurde

- allgemeine Recherche- und Claim-Check-Logik
- Skript- und Dramaturgie-Workflow
- YouTube-Projektstruktur
- 1,10× Voice-over-Aufbereitung mit Pausenstraffung
- Visual-Beat-/Phase-1-Logik
- Phase-3-Grundlogik
- Remotion-Renderer
- QA- und Produktionsskripte

## Was ausdrücklich nicht geerbt wird

- keine alte Themen-Nische oder alte Themen-Prioritätenliste
- kein altes Produktionsprojekt, Skript oder Quellenpaket
- keine alte Bildwelt, Stil-Locks, Charakterregeln, Flow-Prompts oder generierten Bilder

## Produktionsfolge

```text
THEMA + QUELLEN + CLAIM-CHECK
→ FINALES SCRIPT
→ PHASE 1 VISUAL BEATS
→ PHASE 2
→ PHASE 3
→ FINAL-QA
```

Longform-Standard: mindestens 10:00 Minuten final, Ziel meist 11–14 Minuten, sofern das gewählte Thema diese Länge sinnvoll trägt.

# FLOW TEXT STYLE LOCK — CINEMATIC ILLUSTRATED WORLD

**STATUS: BINDING**

Visible text must feel designed inside the same 2D film-world.

## Typography

Use clean modern editorial typography with strong readability and safe margins.

Allowed integration:
- calm asymmetric negative-space title zone
- illustrated board/card/screen when it naturally belongs to the scene
- diagram labels connected to illustrated arrows or objects
- comparison labels
- short phrase integrated into a symbolic illustration

Avoid:
- meme/sticker type
- random floating captions
- giant heavy outline as default
- glow/3D text effects
- multiple unrelated type styles
- PowerPoint-looking boxes disconnected from the illustration

## Cover typography — composition first

The cover title must be composed together with the illustration, not pasted on after the fact.

Hard rules:
- no default full-width headline strip across the top edge
- no title squeezed into a thin top margin
- no generic centered-top placement without a compositional reason
- no text over faces, hands or the key mechanism/object
- prefer an asymmetric title block that balances the main visual subject
- normally use 1–2 title levels: a small psychology-topic kicker plus a larger curiosity/explanation line
- keep outer safe margins generous
- use line breaks intentionally, based on the available shape of the negative space
- title block should occupy a deliberate zone, not the entire frame width

Good cover pattern:
- small integrated topic kicker: `BESITZTUMSEFFEKT`
- larger main line: `WARUM DEINS MEHR WERT IST`
- visual mechanism remains dominant and readable without text

The title position is chosen **after** the visual thesis and focal subjects are planned.

## Schema rule

Schemas may contain more than one short label, but the entire frame must still look illustrated in the same world: matching outlines, color behavior, shading, depth and lighting.

## Cover semantic relationship

Cover typography must support the visible psychology mechanism. It may clarify or name the concept, but it must never substitute for a weak image.

If the image would not communicate the topic with the text temporarily hidden, the cover needs a stronger visual thesis.

## Hard fail

Regenerate when:
- wording is wrong
- letters are malformed or clipped
- extra text appears
- title is a detached full-width top banner
- title placement feels automatic rather than composed
- typography covers the key visual relationship
- visual brand changes
- text is doing all the explanatory work because the illustration itself is vague

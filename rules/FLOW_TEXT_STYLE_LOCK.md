# FLOW TEXT STYLE LOCK — CINEMATIC HUMAN BEHAVIOR WORLD v2

**STATUS: BINDING**

Visible text must feel designed inside `CINEMATIC_HUMAN_BEHAVIOR_V2`.

## Typography

Use clean modern editorial typography with strong readability and safe margins.

Allowed integration:
- calm asymmetric negative-space title zone
- illustrated board/card/screen when it naturally belongs to the scene
- diagram labels connected to illustrated arrows or objects
- comparison labels
- short phrase integrated into a symbolic illustration

Avoid:
- meme/sticker type
- random floating captions
- giant heavy outline as default
- glow/3D text effects
- multiple unrelated type styles
- PowerPoint-looking boxes disconnected from the illustration

## Contrast rule — HARD LOCK

Typography must react to the real background behind it:
- bright background → sufficiently dark text
- dark background → sufficiently light text
- mixed/busy background → first create a calmer compositional text zone instead of adding a thick outline/glow

Never use light text on a light area or dark text on a dark area merely to preserve a fixed brand color.

## Cover typography — composition first, text economy first

The cover title is composed together with the illustration, not pasted on afterward.

Default:
- **one strong main title**
- normally 2–7 words
- 1–2 lines when possible
- compact asymmetric placement
- visual mechanism remains dominant

Additional visible text is allowed only when it materially improves instant understanding, for example:
- two price values required for a price-perception mechanism
- two very short comparison labels
- a technical topic term only when the main title + image are not clear enough without it

Do NOT automatically add a small psychology-topic kicker.

Hard rules:
- no default full-width headline strip across the top edge
- no title squeezed into a thin top margin
- no generic centered-top placement without a compositional reason
- no text over faces, hands or key mechanism/object
- no redundant topic kicker repeating what the image/title already communicate
- keep generous outer safe margins
- choose line breaks from the shape of the available negative space

Good reduced cover pattern:
- main line: `WARUM EINE ZAHL DICH LENKT`
- only the necessary mechanism labels: `199 €`, `129 €`
- no additional `ANKEREFFEKT` kicker unless it clearly improves the thumbnail

## Mood compatibility

Typography remains part of the same editorial system across all moods.

Mood may change:
- background brightness
- local text color needed for contrast
- placement based on negative space

Mood may NOT turn typography into:
- horror lettering
- neon cyberpunk text
- comic speech bubbles by default
- luxury-finance serif branding that breaks the channel style

## Schema rule

Schemas may contain more than one short label when needed, but every visible word must be planned and the entire frame must remain illustrated in the same world.

Prefer fewer labels if the visual relation is already understandable.

## Cover semantic relationship

Typography supports the visible behavioral mechanism; it never substitutes for a weak image.

If the image would become meaningless with text hidden, strengthen the visual thesis before adding more text.

## Hard fail

Regenerate when:
- wording is wrong
- letters are malformed or clipped
- extra text appears
- contrast against the actual background is weak
- title becomes a detached full-width top banner
- title placement feels automatic rather than composed
- typography covers the key visual relationship
- redundant kicker/labels overload the cover
- visual brand changes
- text does all explanatory work because the image is vague

Later images should follow `01.png` for:

## Character reference target

A useful character reference shows a polished hand-drawn 2D Stickman:
- simple round/oval head
- minimal expressive face
- slim simplified body
- thin clearly drawn limbs
- simple clothing
- clean dark outlines
- flat controlled colors
- soft graphic shading

It should not be a bare line doodle or a normal realistic/cartoon human.

## Reference rule

A weak reference must never override the written channel DNA.

Reject only obvious drift:
- photorealistic/realistic human
- 3D/Pixar/anime
- cute/chibi/mascot
- bare whiteboard/classroom stick figure
- conflicting rendering style

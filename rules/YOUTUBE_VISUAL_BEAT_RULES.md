# YOUTUBE VISUAL BEAT RULES

**STATUS: BINDING**

## One thought = one visual beat

Split when the spoken idea changes: action, example, comparison, cause/effect, question/answer, problem/solution, relation or location.

Typical target: about 10–16 spoken words per beat. Clarity wins.

## Observable-scene gate

Before the final image prompt, define:
- `viewerTakeaway`
- `observableEvidence`
- `dominantRelation`
- `literalMetaphorWarning`

Weak:
- show pressure
- visualize insecurity
- show conformity

Strong:
- describe who does what, where, with which object/relation, and what the viewer can literally see

## Do not literalize effect names

A psychology term is not automatically an art instruction.

Spotlight Effect ≠ automatic spotlight.
Anchor Effect ≠ automatic anchor.
Halo Effect ≠ automatic halo.

## Representation choice

Allowed:
- character/human scene
- object/environment scene
- comparison
- schema/mechanism
- text illustration

Choose the clearest representation. No quotas.

## Composition

Default to one coherent visual idea.

Use split/contrast only when the beat genuinely requires two sides.
Use montage only when all parts belong to one inseparable idea.

## Camera

Choose camera because it clarifies the beat:
- wide for environment/relations
- medium for action + context
- close for a specific reaction/object
- low/high only when hierarchy/scale needs it

## Active visual world

Use `rules/PSYCHOLOGY_STICKMAN_WORLD.md`.

Every person must remain in the same established stickman species and illustrator language.

Per beat, adapt only what the script actually calls for:
- clothing
- hair/accessories
- role / status
- age cues
- historical era
- location
- local color/light/mood
- expression/posture

Do not force a permanent protagonist across unrelated beats.
Reuse identity only when the story follows the same person.

## Emotion

When emotion matters, plan observable cues such as:
- gaze
- head angle
- shoulders
- hands
- distance
- who stands/sits
- who blocks or approaches
- group spacing
- interaction with relevant objects

## Text policy

Planned exact German text only.
Otherwise: `ZERO READABLE TEXT`.

# YOUTUBE VISUAL BEAT RULES

**STATUS: BINDING**

## One important thought = one visual beat

Split semantically when the spoken idea changes: new action, mechanism, example, comparison, cause/effect, question/answer, problem/solution or location.

Typical target remains about 10–16 spoken words per beat; clarity wins over word count.

## Every beat plans

- `sceneType`: CHARACTER_SCENE / SCHEMA_EXPLAINER / OBJECT_METAPHOR / COMPARE_VISUAL / TEXT_ILLUSTRATION
- `compositionType`: standard / split / contrast / montage
- `socialDensity`: solo / duo / group / none
- `visualIdea`
- `subject`
- `actionOrRelation`
- `environment`
- `camera`
- `lightingMood`
- `characterDirection` when characters appear
- `textPolicy`
- exact planned Flow texts when needed

## Choosing a scene type

Use CHARACTER_SCENE when a relatable real situation explains the beat best.
Use SCHEMA_EXPLAINER for mechanisms, sequences or relationships that benefit from arrows/labels.
Use OBJECT_METAPHOR when one symbolic object can explain the invisible mechanism faster.
Use COMPARE_VISUAL for two states/options.
Use TEXT_ILLUSTRATION for a memorable concept moment only.

## Same world everywhere

Schemas, objects and text illustrations use the same 2D linework, soft cel shading, controlled colors, light and depth as character scenes.

## Text policy

Allowed:
- `FLOW_EXACT_COVER_TEXT`
- `FLOW_EXACT_KEYWORD_TEXT`
- `FLOW_EXACT_SCHEMA_TEXT`
- `FLOW_EXACT_COMPARISON_TEXT`
- `FLOW_EXACT_TEXT_ILLUSTRATION`
- `NONE`

Schema: optional short title + up to 3 short labels.
Comparison: optional short title + up to 2 short labels.
All text must be exact German planned in Phase 1. `NONE` means ZERO READABLE TEXT.

## Phase 2

Flow applies the global world to each beat. It may vary character identity, place, camera, lighting and representation type while keeping the same illustration language.

Do not copy a previous room/pose simply for consistency. Consistency means same world, not same scene.

## Core

- stylized stickman-inspired characters with clothing and readable body language
- colorful believable everyday environments
- polished 2D animated-film illustration
- clean slightly organic outlines
- soft cel shading
- natural depth
- purposeful cinematic framing and lighting
- controlled rich colors
- meaningful environmental details
- one main psychological beat per frame

## Mixed visual storytelling

A frame may be:
- `CHARACTER_SCENE`
- `SCHEMA_EXPLAINER`
- `OBJECT_METAPHOR`
- `COMPARE_VISUAL`
- `TEXT_ILLUSTRATION`

A stickman is not required in every image. Non-character frames must still look like the exact same world.

## Not allowed

- minimalist whiteboard / bare line-stickman world
- sparse off-white-paper world as channel default
- normal realistic/cartoon humans
- 3D/Pixar/anime
- corporate vector infographic style
- photorealistic environments
- random style changes between scene families

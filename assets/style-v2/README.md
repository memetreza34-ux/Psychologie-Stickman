# Style Reference Pack — Minimal Editorial Stickman World v2

This directory is the permanent visual reference pack for the channel.

Planned approved reference files:
- `style-master.png`
- `anatomy-sheet.png`
- `environment-examples.png`
- `metaphor-examples.png`
- `thumbnail-reference.png`

These files are channel references, not per-video character clones.

Until the PNG set is generated and approved, use `rules/VISUAL_SYSTEM.md` and `rules/visual-system.json` as the source of truth.

## Reference-generation rule

All reference images must use:
- warm off-white background `#F6F3EA`
- charcoal lines `#202124`
- flat simple stickman anatomy
- sparse environment cues
- large negative space
- channel accents only: blue `#3F6EDB`, coral `#E7684A`, green `#4E9B78`, optional amber `#D6A23D`
- no cinematic lighting, no rich detailed environments, no 3D, no semi-realistic humans

Do not approve a reference that depends on a single video's character, location, title or color story.

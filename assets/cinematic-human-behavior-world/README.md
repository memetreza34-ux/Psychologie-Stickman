# Cinematic Human Behavior World v2 — Reference Pack

This folder is the permanent visual-reference location for `CINEMATIC_HUMAN_BEHAVIOR_V2`.

## Important status rule

A filename listed below is a **target/reference role**, not proof that an approved image already exists.

Only files that actually exist here **and have passed** `rules/IMAGE_REFERENCE_LOCK.md` + `rules/STICKMAN_DNA.md` may be used as visual references.

Until an approved image exists, the written visual rules remain authoritative.

## Preferred compact reference system

Do not build a giant conflicting style collage. Use only the references the production genuinely needs.

### 1. Style anchor

Preferred target:
- `style-master.png`

Role: `style-only`.

It may lock:
- mature strict-stickman anatomy family
- linework
- cel shading
- texture
- environment-quality level
- overall 2D psychology-documentary/editorial rendering quality

It does NOT lock one exact person, room, camera, pose, composition or palette.

### 2. Recurring characters

When a recurring character matters, use one or two clean approved images of that same character.

Suggested names:
- `character-a-01.png`
- `character-a-02.png`
- `character-b-01.png`
- `character-b-02.png`

Role: `character-identity`.

One clean image may be enough. A second image is optional and should only be added when it improves identity consistency without contradicting the first.

### 3. Group consistency

Optional:
- `character-group.png`

Use only when group/crowd consistency clearly benefits from a dedicated reference.

### 4. Optional special reference

Use at most one additional approved visual-family reference when useful, for example:
- `schema-reference.png`
- `environment-reference.png`

Not every video needs either.

## Reference creation helper

`character-reference-prompt.txt` contains a helper prompt for generating a candidate mature strict-stickman character reference in Google Flow.

A generated image remains only a **candidate** until it passes the approval gate.

Do not approve a reference that is cute/chibi/mascot-like, broad-shouldered, thick-limbed, too close to normal cartoon-human anatomy, flat/cheap or inconsistent with the intended 2D editorial rendering quality.

## Reference roles

Use references with an explicit purpose:
- `style-only`
- `character-identity`
- `environment-continuity`

Do not use one reference for every possible role automatically.

## Scene/Bild 01

The approved cover may help confirm the video's quality/world continuity after the user selects it, but it is never the permanent channel style master and must not force later images to copy its room, pose, composition or palette.

Google Flow output behavior is separately defined by `rules/FLOW_OUTPUT_MODE.md`.
Final prompt-writing behavior is defined by `rules/FLOW_PROMPT_ARCHITECTURE.md`.

## Reference creation helper

`character-reference-prompt.txt` contains the approved prompt for creating a candidate neutral character sheet in Google Flow.

A generated sheet is only a **candidate** until it passes `rules/IMAGE_REFERENCE_LOCK.md` and `rules/STICKMAN_DNA.md`.

Do not approve a sheet that is cute/chibi/mascot-like, broad-shouldered, thick-limbed or too close to normal cartoon-human anatomy.

References lock illustration language, strict-stickman anatomy, rendering quality and matching mood family — not scene content.

Never clone readable text, exact room, exact pose, exact character identity, exact object arrangement or exact composition unless local continuity explicitly requires it.

Scene 01 of a video is never a replacement for this permanent reference pack.
